# Healthcare Insurance Claims Analysis | SQL Server & Power BI

## Project Overview

This project analyzes healthcare insurance data using SQL Server and Microsoft Power BI to understand insurance charges and explore patterns across customer demographics and lifestyle factors.

## Objectives

Analyze total and average insurance charges.

Compare charges across different age groups.

Categorize individuals based on BMI: Underweight, Normal, Overweight, and Obese.

Analyze insurance charges by gender, region

Identify individuals with the highest recorded insurance charges.

Build an interactive Power BI dashboard to present key insights.

# Tools
Python (pandas)
SQL Server
Power BI (Dax, Visualisation)
